SMS TEST v3.1.0

- Исправлено сохранение URL и истории на Android через JSON-строки SharedPreferences.
- При запуске восстанавливается выбранный профиль.
- Номера принимаются в формате 79991234567 и +79991234567.
- Добавлена настройка POST поля phone с + или только цифры, сохраняемая после выхода.
- Сообщения о сетевых ошибках не раскрывают приватные URL и номера в журнале.
- Сохранена отправка POST внутри приложения для своих SMS API, ограничение запросов и остановка при HTTP 429.
- OAuth/страницы авторизации по-прежнему требуют браузера.
- Сохранены JNI override и GitHub Actions workflow, ранее успешно использованные для сборки Android.
