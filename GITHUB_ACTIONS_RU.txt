SMS TEST v3.1 — получить APK через GitHub

1. Распакуй архив.
2. Открой свой репозиторий GitHub и обнови файлы из папки SMS_TEST_v3.
   Важно: в корне репозитория должен быть pyproject.toml.
   Путь .github/workflows/build-android.yml надо сохранить точно.
3. GitHub -> Actions -> Build Android APK -> Run workflow.
4. После зелёного Success скачай Artifacts -> SMS-TEST-v3.1-Android.
5. Распакуй скачанный архив, внутри APK.

Новое: ввод номера без +, отправка формы из приложения к собственным API,
сохранение ссылок после закрытия и восстановление выбранного профиля.

Не удаляй старую установленную версию, пока не переписал ссылки:
если подпись нового APK отличается, Android потребует удалить старую,
что удалит и её локально сохранённые профили.
